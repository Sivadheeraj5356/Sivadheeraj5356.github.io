Minigrid: two merged fixes in Farama's RL benchmark envs

oss, mergedNov 2026

Minigrid is one of the standard RL benchmark environments. #548: its goal-position heuristic silently hung on grids larger than 16x16 - traced it to the Hilbert-curve traversal ordering and patched it, merged the same day. #546: setup.py read the README with the platform default encoding, breaking pip install -e . on Windows - read it as UTF-8 explicitly.

  • PR - #548, Hilbert-curve hang above 16x16
  • PR - #546, UTF-8 README in setup.py
02

gymnax: four merged fixes in Robert Lange's JAX RL environments

oss, mergedNov 2026

gymnax runs RL environments in JAX on GPU/TPU. #128: the vector wrapper shared one seed across batched environments, collapsing rollout diversity - added per-environment seeding. #129: the Brax adapter reported wrong vector dimensions and properties, breaking downstream wrappers - corrected the adapter. #130: multidimensional Box bounds were not broadcast during Gymnasium space conversion - broadcast them to the right shape. #131: the Gymnasium wrapper shared one metadata dict across environments, so one env's entries leaked into the rest - each environment now keeps independent metadata. All four merged.

  • PR - #128, per-environment seeds
  • PR - #129, Brax adapter dimensions
  • PR - #130, broadcast Box bounds
  • PR - #131, independent wrapper metadata
03

sample-factory #339: batch and action axes in deterministic tuple actions

oss, mergedNov 2026

Sample Factory is a high-throughput reinforcement learning framework. Deterministic policies on tuple-action environments collapsed the batch axis, so agents in the same batch could receive each other's actions. Each agent now keeps its own row; stochastic sampling and non-tuple distributions are unchanged. Merged by the repo owner.

  • PR - alex-petrenko/sample-factory#339
