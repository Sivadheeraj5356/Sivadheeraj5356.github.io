Chat is the command line of AI

Why the text box won, and why the future belongs to artifacts you can touch, not transcripts you scroll.

Every computing era starts with a text box. The terminal won the early decades not because anyone loved typing commands, but because it was universal: one interface, infinite programs, zero design cost per new capability. Chat won AI the same way. A text box can front any model, any task, any domain. Nobody had to design anything, and that is exactly why everything shipped as a chat window.

But it is worth remembering who terminals were actually for. The GUI did not beat the command line by making prompts friendlier. It won by making the state of the system visible and directly manipulable. You stopped describing what you wanted in words and started pointing at the thing itself.

AI is sitting in its own 1983. The transcript is not the work. When I ask an agent to compare flights, the work is a table of options with tradeoffs, not four hundred words of prose I have to parse back into a table in my head. When it drafts a plan, the work is a plan: something I can reorder, strike through, initial. Chat collapses all of that into scrollback, and scrollback is where work goes to be forgotten.

The shape of what comes next: artifacts first, conversation as metadata. The document, the itinerary, the diff, the plan - that is the interface. The conversation that produced it hangs off the side, like version history. You should never have to scroll up to find what the AI made for you. It should just be there, current and editable, and your edits to it should count as instructions.

Interface sketch

A document agent whose chat lives in a margin, not the main window. Every edit you make to the artifact - a deleted paragraph, a moved row, a renamed heading - is captured as intent rather than keystrokes, and the next regeneration respects it. The transcript is demoted to a sidebar called "how we got here." Nobody misses it.

Chat will not die. Terminals did not. It will become what the terminal became: the power tool underneath, not the interface in front.
