NOTES ON HUMAN-AI INTERACTION · 05 / 10

Generative UI should keep its landmarks

Interfaces generated fresh for every task have a problem nobody prices in: nothing stays put.

The dream is seductive: an interface generated for exactly this task, exactly fitted, thrown away after. No menus, no navigation, no forty features when you need two. The catch is that every screen is new, and on a new screen nothing is learnable. Muscle memory is how interfaces disappear from conscious thought. A UI that is never the same twice never disappears. You pay attention to it forever, and attention is the most expensive currency in any product.

What we actually want is a fresh layout wrapped around stable landmarks. The way out is always top-right. The commitment is always bottom-center. Spatial consistency is not boring design; it is the load-bearing structure that lets everything else vary safely.

Small grammar, infinite sentences

Generated UI should compose from a few dozen known blocks - picker, table, timeline, compare, confirm - rather than inventing widgets per task. Users learn the alphabet once, and the model writes new words. Novelty belongs in the arrangement, never in the primitives.

Regeneration is a diff

When the interface changes underneath you, say what changed. "Since you were here: two options added, one removed, prices updated." Otherwise every refresh is a small betrayal, and users learn to distrust the ground they stand on.

The goal is not an interface that is always new. It is an interface that is always familiar in its bones and always specific in its flesh.
