NOTES ON HUMAN-AI INTERACTION · 03 / 10

The audit trail is the interface

When AI works while you are not looking, the review screen becomes the whole product.

An agent that works overnight has a problem no chat window can solve: you were not there. The unit of interaction shifts from the message to the morning after. What did it do? What changed? What do I need to reverse?

Email already taught us how this goes. People do not read digests; they triage them. So design for triage: every item one glance, one decision, one undo. A digest that takes twenty minutes to audit is a product failure wearing a productivity costume.

The reversibility gradient

Not all actions deserve the same gate. Deleting a draft is cheap and reversible; sending it is neither. An agent should act freely at the cheap end of the gradient, report clearly, and hold its breath at the expensive end. Deciding where an action sits on that gradient, for this user, in this context, is most of what "judgment" means in an agent.

Replay, not logs

When something looks wrong, "show me why" should return the three decisions behind the outcome in plain language - not a stack trace, not a chain-of-thought dump. The question a user is really asking is never "what did you compute." It is "what did you assume."

Trust is not built by the agent being right. It is built by the review loop being boring. The hundredth morning you scan the digest and find nothing surprising is worth more than the first morning it did something brilliant. Boring is the goal. Boring is what gets an agent promoted from tool to colleague.
